CleonPDF portable mode

While this file sits next to cleonpdf.exe, CleonPDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the CleonPdfData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move CleonPDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\CleonPDF and
%LOCALAPPDATA%\CleonPDF) instead. If CleonPdfData can't be written (for example on a read-only
drive), CleonPDF says so and uses the per-user folders instead.
